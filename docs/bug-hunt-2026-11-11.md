# Bug hunt, 2026-11-11

Every driver scenario was run (`ui-test.sh`, real-web, real-private, real-ad, real, web, look, bank-idle) plus a new `hunt` scenario for features nothing else covered (find, zoom, Cmd+S, Cmd+L, downloads, bookmarks, settings, untitled pages). The `vpn` and `import-real` scenarios were skipped: one connects the VPN, the other reads the real Chrome profile. Screenshots were checked by eye.

## Cursors (fixed before the hunt)

| | Finding | Status |
|---|---|---|
| C1 | No pointing hand over clickable things (tab rows, icon buttons, chips, cards, menu rows). egui sets the hand on its own `Button` only. | Fixed: one pass at the end of each frame sets the hand over anything that is only clickable. |
| C2 | WebKit pages never changed the cursor: the arrow stayed over links and fields. The window's cursor rect (egui's cursor over the whole view) won over WebKit. Measured with real mouse moves: arrow before, hand/I-beam after. | Fixed: cursor rects are off while the mouse is over a web view. |
