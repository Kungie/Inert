INERT:// · AN APPLICATION PROTOCOL

Descriptions, never code.

Sites send a signed list of what is on the screen. The browser checks it, then draws it. Nothing from the site runs on your Mac.

Three messages. That's the whole web app.

01 · SCREEN What to show 
screen  overview
slot    total   decimal
slot    accounts list ≤ 10
button  Send money → transfer
02 · ACTION What you did 
action  transfer
to      string ≤ 34
amount  0.01 … 10000.00
note    string ≤ 140
03 · RESULT What happened 
result  ok
next    screen overview
checked against
        manifest v3 ✓

Whole kinds of attack, gone by design.

No scriptsNo JavaScript, HTML or plugins reach the browser.
Signed manifestEvery screen must match what the site signed.
No fake fieldsA hacked server can't add a password box.
Typed actionsServers accept only the fields they declared.
Post-quantum TLSTLS 1.3 with X25519 + ML-KEM-768.
Built for agentsAI reads the signed tree, not scraped pixels.
